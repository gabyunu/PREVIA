# PREVIA — Inicio para Codex

Este repositorio comienza **desde cero**. Los prototipos anteriores son antecedentes conceptuales, no código que deba reutilizarse.

## Objetivo de esta carpeta

Dar a Codex contexto suficiente para diseñar la arquitectura y el plan de implementación **antes de escribir la aplicación**.

## Cómo utilizarlo en Ubuntu

1. Extrae este contenido en `~/Proyectos/PREVIA` (los archivos `AGENTS.md`, `README.md` y la carpeta `docs/` deben quedar en la raíz).
2. Abre la carpeta: `cd ~/Proyectos/PREVIA && code .`.
3. Inicializa Git: `git init` (si aún no lo hiciste).
4. Abre Codex desde la terminal con `codex` o desde su extensión de VS Code.
5. Copia el texto de `prompts/01_planificacion.md` y envíalo a Codex.
6. Revisa los documentos que cree y los puntos pendientes; **no autorices la implementación de toda la app** antes de aprobarlos.
7. Cuando apruebes la fase 0, haz un commit para conservar el punto de partida.

## Documentación

- `docs/requirements.md`: alcance, roles y reglas del producto.
- `docs/decisions.md`: decisiones fijadas, propuestas y vacíos reales.
- `docs/architecture.md`: lineamientos tecnológicos y restricciones.
- `docs/roadmap.md`: entregas incrementales y pruebas de aceptación.
- `AGENTS.md`: instrucciones estables para Codex.

**Importante:** La verificación del correo demuestra control del buzón, no matrícula oficial. Los estados académicos son declarados, no verificados por la universidad.
